# Project rules

These are PragMattie PMO's own working rules for intake, the risk register, stage gates, status
reports, client proposals and the dashboard. Informed by generally accepted project management and
AI governance practice. Every number in `policies/` is our own choice.

## Keeping this file

A person writes and changes this file. Agents follow it and never edit it. If a task needs a rule
that isn't here, the agent says so in its summary rather than working from memory.

## People decide

- **R1.** Agent output is a proposal. A named person takes any decision with real consequences, and
  the record shows who.
- **R2.** A person can stop, change or overrule an agent at any time.
- **R3.** What causes a person to step in, and who it goes to, is agreed in advance and written in
  `policies/`.
- **R4.** Each agent has written limits on what it may do alone. Those limits also say when it must
  stop and ask.
- **R5.** Each agent keeps a record of what it did, what it decided and the data it used.

## Security

- **R6.** Access is limited to authorized people. Data is protected in storage and in transit.
  Security is reviewed on a regular schedule.

## Risk

- **R7.** How much risk we will accept is set as a measurable limit for each project objective.
- **R8.** The probability and impact scales are defined up front. They are used for threats and
  opportunities alike.
- **R9.** Some risks don't fit a number, such as ethical or reputational ones. An agent never scores
  these alone; they go to a person.
- **R10.** The risk register holds risks that come from using AI as well as ordinary project risks.

## AI projects

- **R11.** Before building starts on a project that uses AI, a person records whether it is ready,
  covering whether the problem is worth solving, whether AI is the right tool, and whether the data
  is good enough. The result is green, yellow or red. Yellow needs an action with an owner and a
  date, and red stops the work until it is fixed.

## Words

- **R12.** We use one plain name for each thing across the product: sponsor, project manager and
  risk register, not synonyms. Names of stages, gates and other structures in this product are our
  own.
